ACTUALIZARE SI RETESTARE DUPA CORECTII

Ruleaza comenzile pe calculatorul cu RTX 3080, in PowerShell, din proiect.
Nu este necesar sa redescarci modelele sau sa rulezi setup.bat.

1. Actualizeaza sursele dupa ce ti se confirma ca modificarile au fost trimise:

cd 'D:\aaaa\git\instsum'
git status --short --branch
git pull --ff-only

Daca pull afiseaza o eroare, OPRESTE-TE si trimite mesajul. Nu sterge si nu
suprascrie modificari locale pentru a forta actualizarea.

2. Reconstruieste executabilul instalat din sursele actualizate. Copiaza tot
blocul de mai jos. Se foloseste memoria cache a instalarii, fara descarcari.

$runtime = Join-Path (Get-Location).Path 'runtime\setup-v1'
$env:GOPATH = Join-Path $runtime 'go-work'
$env:GOCACHE = Join-Path $runtime 'go-build-cache'
$env:GOENV = 'off'
$env:GOWORK = 'off'
$env:GOTOOLCHAIN = 'local'
$env:GOPROXY = 'off'
$tmp = Join-Path $runtime ("instsum-" + [guid]::NewGuid().ToString('N') + '.tmp.exe')
& (Join-Path $runtime 'toolchain\go\bin\go.exe') build -o $tmp .\cmd\instsum
if ($LASTEXITCODE -eq 0) { Move-Item -LiteralPath $tmp -Destination (Join-Path $runtime 'instsum.exe') -Force -ErrorAction Stop; Write-Host 'Executabil actualizat.' } else { Write-Error 'Compilarea a esuat; executabilul anterior nu a fost inlocuit.' }

Continua doar daca apare "Executabil actualizat." Daca exista o eroare,
trimite-o; un executabil vechi nu contine corectiile.

3. Configureaza temporar calea NVIDIA verificata in logurile anterioare:

$env:IGX_NVIDIA_SMI_PATH = 'C:\Windows\System32\DriverStore\FileRepository\nv_dispi.inf_amd64_feedb8c0271ca811\nvidia-smi.exe'
& $env:IGX_NVIDIA_SMI_PATH --query-gpu=index,name,memory.total,memory.used --format=csv,noheader,nounits

Daca apare eroare sau RTX 3080 nu mai este la index 1, opreste-te si trimite
mesajul/tabelul. Setarea ramane valabila doar in aceasta fereastra.

4. In aceeasi fereastra activeaza monitorizarea si porneste aplicatia:

$env:IGX_GPU_MONITOR = 'true'
.\start.bat

Aplicatia foloseste URL-ul din start-url.txt. Asteapta pana se termina si
apasa o tasta la mesajul de final. Monitorizarea este prin esantionare:
nu garanteaza ca toate varfurile de memorie au fost observate.

5. Trimite pentru analiza:
- cel mai nou logs\instsum-*.log;
- result.json si result.md din noul director out\run-... afisat la rulare;
- llama-server.log din acel director, daca exista.

Verifica fisierele inainte de a le trimite: pot contine cai personale, URL-uri
si continutul postarii. Nu trimite parole, cookie-uri sau token-uri. Unele
fisiere logs, out si start-url.txt sunt deja urmarite in Git in acest
repository: nu le comite automat.
